# flatlandian

A small 2d library to support other projects.

Uses [pygame-ce](https://pyga.me/)'s
[Vector2](https://pyga.me/docs/ref/math.html#pygame.math.Vector2) class.

## Add to a project

```shell
uv add git+https://github.com/recreational-projects/flatlandian --tag v0.x.x
```

## Development

Open local documentation browser:

```sh
uv run pdoc flatlandian
```
